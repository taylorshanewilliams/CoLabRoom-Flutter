# CoLabRoom 0.4.0 Beta Tester Guide

Thank you for helping test CoLabRoom. This build is an Android-first beta focused on reliable songwriting, import, song-sheet, and live-performance workflows.

## Install and update

Install the signed 0.4.0 APK over the existing CoLabRoom beta. Android should offer **Update**, not require an uninstall. Keep the previous APK available as a rollback build.

## Ten-minute test

1. Open or create a Room and confirm existing projects are still present.
2. Open a song. Type, paste, select across multiple lyric lines, delete several lines, then leave and reopen the song. Confirm the latest document is saved.
3. Choose **Import Song**. Test one of: pasted lyrics/chords, PDF, `.xlsx`, CSV/TSV, DOCX, RTF, text/Markdown, OpenDocument spreadsheet, or a public Google Sheet link.
4. Review the detected full lyric lines, section labels, chords, and tab before importing. Test both **Add to end** and **Replace song** on non-critical test songs.
5. Open **Song Sheet**. Correct, move, add, and remove a chord. Close and reopen the sheet to confirm the correction persists.
6. Open **Live**. Test Slow/Medium/Fast or Song Time. With a reference recording, test Synced mode and complete **Tap Sync** through an intro or instrumental gap.
7. Record and play a line voice note. Delete or replace it, then verify the song does not unexpectedly close or switch Rooms.
8. Rotate the phone, background and reopen the app, and test once on a weak connection if practical.

## Report a bug

Open the song’s menu and choose **Send beta feedback** immediately after the problem. Include:

- what you tapped just before it happened;
- what you expected;
- what actually happened;
- whether it happens every time;
- the song/import file type involved.

Automatic vocal and chord analysis is still a draft assistant. Accuracy feedback is useful, but manual chord correction and Tap Sync are the intended finishing tools in this beta.

## Privacy notes

Rooms are visible only to members. Imported documents are parsed on the device. A Google Sheet is downloaded only from the sharing link supplied by the tester. Voice notes and reference recordings are stored with the private Room. Vocal transcription and chord analysis run on the Android device in this beta.
